Personal publishing tool

Leon Auto

Leon Auto is a personal desktop tool that renders short educational 3D videos starring Léon, a cartoon mascot, and publishes them to its owner's own TikTok account through the official TikTok Content Posting API.

Leon Auto est un outil personnel qui crée des vidéos éducatives en 3D avec la mascotte Léon et les publie sur le compte TikTok de son propriétaire, via l'API officielle de TikTok.

How it works

  • Login Kit (user.info.basic): the owner signs in once to authorize the tool and to show which account will receive the post.
  • Content Posting API (video.publish): before each post, the owner reviews the video on a local confirmation page (preview, account, caption, privacy chosen manually, interaction settings, content disclosure, consent) and clicks Post. The video file rendered on the owner's computer is then uploaded and marked as AI-generated content.
  • The tool runs only on the owner's computer. It has no public users, no server and no sign-up.
